Two methods

Pick the right tool for the job

AI for anything. Colour-key for fast, logo-style work. Both output a clean RGBA PNG.

Method 1 — AI (U2-Net)

Deep learning via rembg. Handles hair, fur, glass, and complex scenes. Downloads the model once (~170 MB) and runs fully offline after that.

Any image Hair & fur Semi-transparent GPU optional

Method 2 — Colour-key

Pure NumPy + Pillow. Euclidean distance in RGB space with a Gaussian-blurred alpha mask. Lightning fast for logos with solid backgrounds.

Installation

Up and running in minutes

Python 3.8+ required. Tested on 3.9 through 3.12.

01

Clone the repo

Single file — no package structure needed.

02

Install core deps

Pillow and numpy are always required.

03

Add AI deps (optional)

Only needed for --method ai. Choose CPU or GPU.

04

Run it

Model downloads once on first AI run, then cached forever.

bash 
# 1. Clone
git clone https://github.com/Biraj2004/removed_bg
cd removed_bg

# 2. Core deps (always)
pip install Pillow numpy

# 3a. AI method — CPU
pip install rembg onnxruntime

# 3b. AI method — NVIDIA GPU
pip install rembg onnxruntime-gpu

# Or use requirements.txt
pip install -r requirements.txt
Usage

Three ways to pass input

Single file, glob pattern, or an entire directory — all handled.

single file 
# Output auto-derived as photo_nobg.png
python removed_bg.py photo.jpg

# Explicit output path
python removed_bg.py photo.jpg out/clean.png

# Colour-key — white background
python removed_bg.py logo.png --method colorkey --bg-color 255,255,255
glob pattern — always quote it 
# Quote the pattern so the shell doesn't expand it
python removed_bg.py "images/*.png" --batch --out-dir ./nobg/

# Multiple patterns in one call
python removed_bg.py "icons/*.png" "banners/*.jpg" --batch --out-dir ./nobg/
directory (non-recursive) 
# All supported images inside the folder
python removed_bg.py images/ --batch --method ai --out-dir ./output/

# Supported: .png .jpg .jpeg .webp .bmp .tiff
# Subdirectories are skipped
batch colour-key 
# Colour-key on a folder, white background, soft edges
python removed_bg.py assets/ --batch \
  --method colorkey \
  --bg-color 255,255,255 \
  --tolerance 35 \
  --feather 3 \
  --out-dir ./nobg/
Options

All flags at a glance

output
auto
Output PNG path. Defaults to <stem>_nobg.png in the same folder. Not used with --batch.
--method
ai
ai — U2-Net deep learning. colorkey — fast solid-colour removal.
--bg-color R,G,B
0,0,0
Background colour to remove. Colour-key only. Example: 255,255,255 for white.
--tolerance N
30
RGB Euclidean distance threshold. Raise to 50–80 for JPEG artefacts. Colour-key only.
--feather N
3
Gaussian blur radius on the alpha mask (0–10) for smooth edges. Colour-key only.
--batch
off
Enable batch mode. Required for multiple files, glob patterns, or a directory.
--out-dir DIR
—
Output directory for batch mode. Created automatically if it doesn't exist.
--quiet
off
Suppress all log output. Errors still appear on stderr. Useful in shell pipelines.
--version
—
Print the script version and exit.
How it works

Under the hood

AI — U2-Net via rembg

1

Open image and convert to RGBA.

2

Feed to U2-Net ONNX model. It predicts per-pixel foreground probability.

3

Apply alpha matte — handles hair, fur, semi-transparent edges.

4

Save RGBA PNG. Model cached at ~/.u2net/ after first run.

Colour-key algorithm

1

Convert to RGBA float32.

2

Per-pixel Euclidean distance from --bg-color in RGB space: dist = √((R−Br)²+(G−Bg)²+(B−Bb)²)

3

Build alpha mask: dist < tol → 0.0 · linear ramp in feather zone · dist ≥ 2×tol → 1.0

4

Gaussian blur (radius = --feather) for sub-pixel anti-aliasing. Write RGBA PNG.

Semi-transparent pixels = edge matting. Healthy range: 3–10%. Too low = jagged edges. Too high = BG colour bleeding into subject.

Tech stack

What's inside

No cloud APIs. No web services. Pure local processing.

Python 3.8+

Runtime. Tested on 3.9, 3.10, 3.11, 3.12.

Pillow

Image I/O, Gaussian blur, RGBA operations.

NumPy

Vectorised per-pixel distance and mask computation.

rembg

U2-Net model wrapper for the AI method.

onnxruntime

ONNX inference engine — CPU and CUDA GPU.

Limitations

Good to know

Colour-key needs a uniform background. Don't use it on photos, gradients, or JPEG-heavy edges. Use --method ai instead.

AI method requires the U2-Net model. Downloaded automatically to ~/.u2net/ on first run. In restricted networks, pre-download it manually.

Directory scanning is non-recursive. Only files directly inside the given folder are processed. Subdirectories are skipped.

Very fine detail may need touch-up. Individual hairs, wispy smoke, or transparent glass may not be perfectly matted even with AI — a quick pass in a graphics editor can fix it.
